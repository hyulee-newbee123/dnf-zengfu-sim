# 增幅机 · DNF 手游模拟器 v1.2

地下城与勇士手游增幅网页模拟器：次元灵驿增幅、置换、自动增幅、期望演算。  
**公益开源、仅供娱乐。**

## 在线地址

https://hyulee-newbee123.github.io/dnf-zengfu-sim/

手机或电脑浏览器打开即可。点一下页面后才会出声。

若 GitHub Pages 打不开，可换网络，或下载本仓库后双击 `打开模拟器.bat`。

## 怎么玩

1. **生成**：选好等级，生成武器或非武器胚子进背包  
2. **增幅**：点胚子放进增幅机，手动打或开自动增幅 
3. **置换**：胚子等级高于身上对应部位才能互换  
4. **演算**：按单次概率估算打到目标的消耗  
5. 背包可清空  

成功 / 降级 / 破坏按规则表独立判定。数值、光色、动画都在 `js/config.js`，改完刷新即可。
